\# RTL Design and Verification of 4-bit Adder cum Subtractor



\## Project Overview

This project implements a 4-bit Adder cum Subtractor using Verilog HDL with a gate-level ripple carry architecture.



The circuit performs both binary addition and subtraction based on the mode input.



\## Features

\- 4-bit binary addition

\- 4-bit binary subtraction

\- Ripple Carry Full Adder architecture

\- Carry and borrow detection

\- Signed overflow detection

\- Exhaustive functional verification



\## Operation

| Mode | Operation |

|---|---|

| 0 | Addition (A + B) |

| 1 | Subtraction (A - B) |



\## Tools Used

\- Verilog HDL

\- EDA Playground

\- Icarus Verilog

\- EPWave



\## Project Files

\- `design.v` – Gate-level design implementation.

\- `testbench.v` – Verification testbench.



\## Verification

The testbench performs 512 test cases:

\- 256 addition cases

\- 256 subtraction cases



Expected simulation output:

`ALL TESTS PASSED`
